# efficient-query-repair-demo
A demonstration system for efficient query repair based on aggregate constraints.

## Requirements

- python >= 3.10

## Setup

### Create virtual environement

```sh
just create-venv
```

of use direnv

```sh
direnv allow
```

### install requirements

```sh
pip install -r query-repair-backend/requirements.txt
```

### Build the repair module and install

```sh
python -m pip install -e query-repair-module
```
